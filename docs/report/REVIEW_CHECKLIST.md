# 报告审核清单

每章提交后按此清单审核。问题分为三级：**CRITICAL**（事实错误、编造结果、口径混用，必须改）、**MAJOR**（缺少课程要求的内容、逻辑断链，应当改）、**MINOR**（措辞、格式问题，建议改）。

## A. 事实与证据（每章都要检查）

- [ ] 每个数字都能在 `results/`、`experiments/eda/`、`configs/` 或代码中找到出处，且四舍五入一致（如 468.3、437.2、35,058）
- [ ] 原始标签和平均后标签、select 和 refit、35,158 行和 35,058 行、17,900 组和 17,777 组没有混用
- [ ] 没有把未运行的实验（树模型、消融、Kaggle 分数）写成结果
- [ ] 没有因果断言；相关性用 "is associated with" 等表述
- [ ] 引用的论文真实存在，作者、年份、会议正确，并且引用位置与论文内容相符
- [ ] 与代码一致：token 数（29+CLS）、层数、学习率、遮蔽概率、EMA、早停耐心值

## B. 课程要求覆盖

- [ ] Motivation：说明了问题、挑战和受益者，不是只为了 Kaggle 排名
- [ ] EDA → 预处理：每个预处理步骤都能指回一条 EDA 发现
- [ ] Methods：说明了选择理由、超参如何确定、讨论了备选方案，高级方法附有引用
- [ ] Evaluation：评估设置正确（时间外验证），有比较，说明了在哪些情况下表现差、原理性局限和改进方向
- [ ] 作者栏有队名、姓名、学号；附录有分工
- [ ] 正文 ≤ 8 页（不含参考文献和附录），去掉附录后正文仍然完整可读

## C. 逻辑与结构

- [ ] Introduction 中的挑战在后文都有对应的回应或局限说明
- [ ] 贡献列表中的每一条都有章节支撑，强度不超过证据
- [ ] 每章开头一句能接上上一章
- [ ] Discussion 没有引入新结果；Conclusion 没有新主张
- [ ] Abstract 中的数字与第 VI 章一致

## D. 图表

- [ ] 每张图表都在正文中被引用和解释
- [ ] 标注了样本、时间范围、单位（SGD/month、m²）和评估口径

## E. 语言与格式

- [ ] 英文学术语气，避免 AI 腔词汇（delve、leverage、crucial、seamless 等）和滥用破折号

- [ ] `latexmk` 编译无错误、无未定义引用、无 overfull 越界
