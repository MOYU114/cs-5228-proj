检索前冻结的问题：

- RQ1：2024–2026 的哪些现代 CPU/GPU 表格学习、基础模型或时间自适应机制适合 150,000 行、高基数楼栋与混合类型的租金回归？
- RQ2：面对最长 16 个月的时间间隔、重复楼栋和缺少历史生效日期的辅助数据，各机制的收益假设、失效条件及验证要求是什么？
- RQ3：在成本作为软偏好的前提下，综合数据适配、实验信息量、工程可行性与计算需求，哪五个候选方案优先，如何用受控实验否证它们？

角度：不仅比较表格回归算法，也区分静态属性拟合与未来时间外推。可行性排序不等于 RMSE 排名。EDA 与外部论文各自提供不同证据，不能互相替代。

资源口径：CPU/GPU 均可，低成本是软偏好。用户未提供现有 GPU、显存、CUDA 环境或付费额度，不能推断已经具备某块 GPU。4–8 CPU 核、16 GB RAM 仍仅为旧版规划参考。此前 15/75 分钟预算不再作为候选准入门槛。团队成员每周工时和熟练度未知。训练时间、内存和开发工时如无实测必须标为预算或估计。

初始阶段的四个独立检索视角（以下为范围演变记录，非当前五项清单）：

1. 成熟树模型及其 CPU / 类别处理实现：CatBoost、LightGBM、XGBoost。
2. 统计学相邻方法：稀疏正则化、加性/分层、房屋属性与时间分解。
3. 反方及近期表格学习进展：树对神经网络的证据边界、TabM / TabPFN 等近期结果和成本。
4. 应用与验证：HDB 租金、非平稳预测、时空结构、EBM 的可解释实现与验证接口。

此次增量检索：单卡神经表格训练（TabM、FT-Transformer及相邻机制）、树模型 GPU 后端与成本/复现边界、表格基础模型适配与反方证据。沿用原检索语料，定向补充，不重做已完成 EDA。
